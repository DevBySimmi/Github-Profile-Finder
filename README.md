🔎 GitHub Profile Finder

«✨ Discover GitHub profiles instantly with a cute and simple interface! 💗»

GitHub Profile Finder is a desktop application built with Python, Tkinter, and the GitHub REST API.

Simply enter a GitHub username and the application fetches useful public profile information such as the user's avatar, name, bio, repositories, followers, following, location, website, and account creation date.

✨ Features

- 🔎 Search GitHub users by username
- 👤 Display profile name and username
- 🖼️ Display GitHub profile avatar
- 📝 Show profile bio
- 📦 Show public repository count
- 👥 Show followers
- 💗 Show following
- 📍 Show location
- 🌐 Show personal website
- 📅 Show account creation date
- 🔗 Open GitHub profile directly
- ❌ Handle invalid usernames
- 🌐 Handle connection errors
- ⏳ Handle request timeouts
- 🎀 Cute pastel GUI
- ⚡ Fast and lightweight

🛠️ Technologies Used

- 🐍 Python 3
- 🖥️ Tkinter
- 🌐 GitHub REST API
- 📡 Requests
- 🖼️ Pillow

🚀 Installation

1. Open the project folder

cd GitHub-Profile-Finder

2. Install dependencies

pip install requests pillow

3. Run the application

python main.py

🔍 How to Use

1. Launch the application.
2. Enter a GitHub username.
3. Click 🔍 Search.
4. Wait for the profile information to load.
5. Explore the user's public profile information.
6. Click 🌐 Open GitHub Profile to visit the profile in your browser.

💡 Example

Try searching for:

octocat

The application will display the available public information for that GitHub account.

🌐 GitHub API

This project uses the GitHub REST API to retrieve publicly available user profile information.

No GitHub login or personal access token is required for basic profile searches.
